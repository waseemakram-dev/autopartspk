# ⚡ Gemini Auto Batch Chrome Extension Installation Guide

Yeh extension aapki tamam 300 images ko **gemini.google.com** par automatically upload karegi, prompt degi, response aane par image download karegi aur agli image par move karegi!

---

## 🛠️ Chrome Mein Extension Load Karne Ka Tareeqah (1 Minute Setup):

1. **Google Chrome** kholain.
2. Address bar mein yeh type karke Enter dabayein:
   `chrome://extensions/`
3. Top right corner par **"Developer mode"** ka switch ko **ON** kar dein.
4. Top left par **"Load unpacked"** button par click karein.
5. Is folder ko select karein:
   `d:\waseem desktop\clients\waliha\spare parts\gemini_auto_extension`

---

## 🚀 Batch Process Run Karne Ka Tareeqah:

1. Chrome mein [gemini.google.com](https://gemini.google.com) kholain.
2. Extension icon (Extensions puzzle piece) par click karke **"Gemini Auto Product Image Batcher"** ko open karein.
3. **Select All Images** button par click karke apni tamaam 300 raw images select karein.
4. **Delay** 10-15 seconds set karein.
5. **🚀 Start Auto Batch Process** par click kar dein!
